# Agenda Pro

Agenda Pro es una agenda web profesional para gestionar contactos, favoritos y tareas desde una interfaz clara, rápida y consistente. Está pensada como una base sólida para un CRM personal o un panel de gestión de relaciones.

## Lo que aporta en un contexto profesional
- **Visibilidad inmediata** de contactos clave, con accesos directos y detalle completo.
- **Flujo unificado** entre contactos, favoritos, tareas y perfil sin perder contexto.
- **Diseño coherente** con un sistema visual consistente, componentes reutilizables y micro‑interacciones suaves.

## Funcionalidades principales
1. **Gestión de contactos** con tarjetas visuales y acciones rápidas.
2. **Vista de detalle** con información completa por contacto.
3. **Favoritos** para priorizar relaciones importantes.
4. **Tareas** con prioridad y edición rápida.
5. **Perfil** con resumen y métricas básicas.

## Tecnologías
- **HTML5** para la estructura de vistas.
- **CSS3** con variables, glassmorphism y layout responsive.
- **JavaScript** para renderizar contenido dinámico y navegación contextual.
- **LocalStorage** para mantener el contacto seleccionado.

## Cómo ejecutar
1. Abre `Index\index.html` en tu navegador.
2. (Opcional) Usa una extensión tipo Live Server en VS Code para recarga automática.

## Estructura del proyecto
```
AgendaWeb-2024003/
├─ Index/               # Vistas HTML
├─ Styles/              # Estilos globales y de páginas
├─ Js/                  # Lógica de contactos y tareas
└─ Images/              # Recursos visuales
```

## Notas de diseño
El proyecto mantiene un **sistema de diseño consistente** (tokens de color, tipografía uniforme y estados de interacción), asegurando una experiencia cuidada y lista para crecer hacia un producto real.
